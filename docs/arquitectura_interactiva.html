Aegis-PIMS: Agente Auditor-Capacitador

Arquitectura Standalone basada en ISO/IEC 27701:2025 (78 Controles), ISO 29100 y Ley Peruana N.° 29733 (ANPD - MINJUSDH).

✓ ISO 27701:2025 Standalone (Sin dependencia ISO 27001) ● Orquestador Agéntico + GraphRAG + DSPM

01 Capa de Presentación e Interfaz de Usuario (React + Tailwind CSS)

Frontend SPA

💬 Chatbot Capacitador Pericial

Diálogo interactivo para responder dudas normativas, ilustrar con multas reales en UIT de la ANPD y guiar la remediación en código.

📊 Visualizador DSPM de Base de Datos

Renderizado de tablas SQL con semáforo de colores por columna (DNI, tarjetas, hashes vulnerables, datos biométricos y de salud).

📈 Matriz de Brechas (78 Controles 2025)

Selector de rol (Controller: 31 / Processor: 18 / Seguridad: 29) con métricas de cumplimiento de ISO 27701:2025.

02 Capa de Orquestación Agéntica (FastAPI + LangGraph)

Agentic State Machine

Agente Orquestador Central: Gestiona el estado de la auditoría. En lugar de hacer búsquedas ciegas de texto, invoca a dos herramientas de alta precisión para nutrir al LLM con hechos verificados.

Herramienta 1 (Empresa) DSPM + Vector

Inspector de Evidencia Corporativa

  • • Sub-Módulo DSPM (Esquemas SQL): Parser AST con sqlglot para clasificar PII sin chunking ni alucinaciones.
  • • Sub-Módulo Documental: Almacén vectorial para políticas de privacidad, SLA y contratos de tratamiento.
Output: Estructura JSON de riesgos y hechos técnicos
Herramienta 2 (Normativa) GraphRAG + BM25

Catálogo PIMS & Casuística ANPD

  • • Grafo de 78 Controles (ISO 27701:2025): Mapeo directo a los 11 principios de ISO 29100 y Ley 29733.
  • • Retriever Híbrido de Sanciones: Resoluciones sancionadoras de la ANPD (MINJUSDH) con montos reales en UIT.
Output: Controles aplicables y precedentes sancionadores

03 Motor de Inferencia Local y Rol de Capacitador (Ollama)

LLM Execution Layer

🧠 Inferencia Local Segura

Ejecución 100% privada y offline mediante Ollama (Llama 3 8B / Qwen 2.5 7B). Garantiza que los esquemas de base de datos y políticas de la empresa jamás salgan a internet ni vulneren el principio de seguridad.

🎓 Rol: Privacy Awareness & Gap Coach

Personalidad pedagógica y constructiva. Evalúa brechas frente a los 78 controles de ISO 27701:2025, cuantifica el riesgo de multa ante la ANPD (MINJUSDH) y entrega código o scripts SQL de remediación inmediata.
